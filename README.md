# 🩺 AI Patient Management System

An AI-powered healthcare platform built with FastAPI, Machine Learning, SQLAlchemy, and JWT Authentication. The system enables secure user management, diabetes risk prediction, patient record management, and analytics through an interactive dashboard.

## 🚀 Live Demo

https://ai-patient-management-system.onrender.com

## ✨ Features

- 🔐 Secure JWT Authentication
- 👤 User Registration & Login
- 🧠 Diabetes Prediction using Machine Learning
- 📊 Interactive Analytics Dashboard
- 📜 Prediction History Tracking
- 🏥 Patient Management CRUD Operations
- 📈 Data Visualization with Charts
- 🌐 Cloud Deployment on Render
